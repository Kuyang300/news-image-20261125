A program that writes one image summing up the world's news of Wednesday, 25 November 2026: China's Shenzhou-24 carries the first Pakistani astronaut into orbit, a hostage standoff in a Cartagena supermarket, Zelenskiy's confirmation of the Gulf of Finland ship strike, the Antalya climate summit ending without a deal, and the Australia–Solomon Islands security pact.

`main.ts` (Node 22, standard library only) decodes the bundled `entry.b64.txt` and writes it to `/output/entry.png`. Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
